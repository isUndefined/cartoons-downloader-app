# Бинарные компоненты для разработки и сборки

В Git находятся исходники, лицензии и метаданные. Готовые EXE/DLL, стандартная
библиотека Python и WebView2 Runtime хранятся вне Git.
Сборка и запуск сами зависимости не скачивают.

## Подготовка новой рабочей папки

В исходной рабочей папке компоненты уже подготовлены. Для новой копии проекта
перенеси из неё следующие каталоги с сохранением структуры:

| Каталог | Содержимое |
| --- | --- |
| `runtime/python/` | Полный CPython 3.13.16 x64 со стандартной библиотекой и лицензиями |
| `tools/yt-dlp/` | `yt-dlp.exe` и лицензии |
| `tools/deno/` | `deno.exe` и лицензия |
| `tools/ffmpeg/` | `ffmpeg.exe`, `ffprobe.exe` и лицензия |
| `tools/webview2/` | Fixed Version Runtime 155.0.4283.62 x64, SDK DLL, лицензии и инвентарь |
| `build/installer-tools/inno-7.1.0/` | Компилятор Inno Setup 7.1.0 x64 с `ISCC.exe` и `License.txt` |

`runtime/` и `tools/` также можно скопировать из подготовленного portable-пакета
этой версии. Компилятор Inno Setup поставляется отдельно.
Пользовательские `data/`, `downloads/`, `temp/` и `logs/` для сборки не нужны.

## Закреплённые версии и источники

- `BUNDLED_COMPONENTS.sha256` — SHA256 Python и медиапрограмм.
- `runtime/python/PYTHON.json` — версия и параметры Python.
- `tools/webview2/DEPENDENCY.json` — версии, URL и SHA256 архивов Runtime и SDK.
- `tools/webview2/FILES.sha256` — инвентарь WebView2.
- `packaging/installer-toolchain.json` — официальный URL, версия и SHA256
  установщика и компилятора Inno Setup.

При подготовке из исходных дистрибутивов используй закреплённые версии и хеши.
Замена компонента требует обновления метаданных и проверки приложения.
Для Inno Setup проверяй подпись издателя Pyrsys B.V. перед запуском его установщика.
Подготовка компилятора выполняется отдельно от офлайн-сборки приложения.

Сохраняй лицензии рядом с компонентами.
Дополнительные условия — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Проверка готовности

Из корня проекта:

```powershell
.\BUILD_SETUP.bat --no-pause --check-only
.\runtime\python\python.exe -B verify_package.py
```

Первая команда проверяет предпосылки сборки и компилятор. Вторая проверяет файлы,
хеши, синтаксис Python, импорты модулей интерфейса и запуск встроенных утилит.
После успешных проверок запускай `BUILD_SETUP.bat` для полной сборки.
