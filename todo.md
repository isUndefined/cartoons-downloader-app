# Задачи Cartoon Downloader

Актуально на 18 октября 2026 года. Текущая версия: 0.30.3.

- [ ] Проверить нехватку места на отдельном физическом MTP-устройстве.
  Пользователь отложил сценарий до появления подходящего устройства.
  При отказе исходник должен сохраняться, успешная передача не записываться.
- [ ] Проверить установку, запуск, обновление и удаление на чистой Windows
  без установленного Python и браузера, включая сохранность библиотеки и настроек.
- [x] Уменьшить поставку без замены оконного движка.
  В 0.30.1 исключены 35 отладочных `.pdb` (58,15 МиБ), Deno заменён на официальную
  release-сборку той же версии 2.9.7, FFmpeg/ffprobe используют семь общих DLL.
  Папка приложения: 1322 → 968 МиБ (−26,8%); Setup.exe: 402 → 333 МиБ (−17,1%).
  Проверены реальная загрузка 720p H.264/AAC, слияние, ffprobe, декодирование,
  перемотка, обработка VP9/Opus, запуск окна и штатное завершение готового пакета.
  Очистка символов при обновлении проверена отдельно: изменённые и неучтённые
  файлы, обходы пути и цель junction сохраняются.
- [ ] Оценить дальнейшее уменьшение поставки и варианты поставки WebView2.
  Текущий Fixed Version остаётся полностью встроенным.
- [ ] Выпустить итоговый Setup.exe после оставшихся проверок.
  Сборка через BUILD_SETUP.bat и инструкции уже подготовлены.

- [x] Подготовить онлайн-установщик 0.30.2: около 13 МБ, Python включён,
  yt-dlp, Deno, FFmpeg и частный WebView2 скачиваются из закреплённых источников.
  Проверены установка через интернет, хеши 964 установленных файлов, запуск окна,
  штатный выход, отказ обновления при работающем приложении, недоступная загрузка
  и неверный SHA256 без изменения файлов и данных. Удаление убирает скачанные
  инструменты и сохраняет библиотеку. Проверки выполнялись в отдельной регистрации;
  проверка на чистой Windows остаётся открытой.
- [ ] Повторно использовать неизменившиеся компоненты при обновлении онлайн-версии,
  проверяя их хеши. Первый вариант скачивает весь комплект при каждой установке;
  в пределах повторной попытки уже проверенные загрузки используются повторно.
- [x] Подготовить выпуск 0.30.3 со скомпилированным backend: исходники Python/C#,
  SQL и текстовые ресурсы интерфейса исключены из поставки; миграции и интерфейс
  встроены в EXE, MTP-помощник собирается в DLL. Проверены новая база и миграция
  старой базы с сохранением настроек, интерфейс, реальная загрузка 720p H.264/AAC,
  декодирование и перемотка, запуск окна и штатный выход. Онлайн-установщик
  проверен поверх поставки 0.30.2: прежние исходники и разработческий Python
  удаляются, ошибки сети/SHA256 не меняют установку, удаление сохраняет данные.
  Отдельно проверены защита изменённых и неучтённых файлов, обходы пути и junction.
  Компиляция затрудняет чтение кода, но не исключает обратный анализ.

Тестовые скрипты и отчёты удалены по запросу пользователя перед публикацией в Git.
Сборка проверяет целостность компонентов, синтаксис Python, модули интерфейса,
запуск встроенных утилит и форматирование JavaScript/CSS/HTML.
